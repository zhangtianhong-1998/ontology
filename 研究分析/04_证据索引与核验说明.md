# 证据索引与核验说明

核验日期：2026-09-20。

## 1. 证据使用方法

- **L01—L18**对应用户提供的18篇PDF及中文译文，共270个PDF物理页。主文事实优先回到PDF；译文和补充问答不作为独立实验证据。
- **E01—E16**对应扩展报告中的研究，**S01—S03**为标准和辅助工具组，**P01**为新近公开实现。E01为历史方法的摘要/书目信息核验；其余扩展论文按报告相关方法、结果和局限读取，不宣称进行了系统综述或穷尽全部文献。
- 论文分数均为作者报告，没有在本机重新训练、调用模型或重跑完整基准。源码检查、许可证检查、原表渲染与结果复现是不同工作。
- 本报告将“原文事实”“作者解释”“本报告推论/建议”分开。对未发现代码/许可证的项目，只报告本次核验范围，不推定它在所有位置都不存在。
- p为从1开始的PDF物理页码；不是书刊页脚号。带页码文本使用 `===== PDF PAGE n =====`，便于搜索后回看原页。原表疑点已针对性渲染核对，不声称每一页都进行了视觉审校。

## 3. 关键结论与原始定位

| 结论/需防止的误读 | 原始证据 | 能支持到哪一步 |
|---|---|---|
| LLMs4OL没有实测完整构建流程 | L01 p7图1、p12表3 | 三类给定输入的子任务效果 |
| OLLM有监督文本到分类图 | L02 p4–5方法、p6–7指标、p9表1 | 分类图生成；未证明公理和业务映射 |
| 2024/2025任务字母变化 | L03 p3–4；L17 p3–6 | 必须按实际任务对齐 |
| 2025 Text2Onto是合成文本 | L17 p5 | 受控恢复标签；自然资料泛化需另测 |
| 简单词面基线有竞争力 | L05 p13表4 | OBI特定层级任务，非所有领域 |
| Phoenix CoT缺独立对照 | L06 p3–5 | 报告组合结果，无法隔离CoT贡献 |
| LABKAG上下文/规则有收益及代价 | L07 p7表2、p9表3 | 召回/精确率和领域间表现需一起看 |
| DREAM审议并非处处收益 | L08 p6表2、p7表3 | 选定judge的两域改善、一域持平 |
| IRIS过滤/定义组合有直接对照 | L09 p12表3、p13表4–5 | 联合策略有效；训练负例与候选贡献未隔离 |
| CUET复杂组合仍有很低精确率 | L10 p9–10表4–5 | 原型任务结果；部分成本主张缺明细 |

| T-GreC方法跨数据集效果不同 | L12 p4表1、p5表2 | 各域重训的1NN分类，非提示或零样本迁移 |
| Alexbek attention不等于逻辑推理 | L13 p6–7方法、p12未来工作 | 监督边预测 |
| silp排名第一不能替代绝对质量 | L14 p9表1；L17 p7表3 | FoodOn D仅0.0084 |
| SEMA没有跨域验证 | L15 p3–6；L17 p7 | MatOnto单域关系判断 |
| 前言不提供独立实验 | L16 p1–2 | 赛事情境说明 |
| 分类高分不证明关系构建可靠 | L17 p7表3 | 同届分任务结果，不做跨指标总排序 |
| 人机协作的时间/查询证据边界 | L18 p13、15–16、23–25 | 单案例时间，查询执行/有结果/可回答性分开 |
| AutoSchemaKG正式版改变摘要数字 | E06 2026ACL p1、p5表6、p18附录C.2 | 92%语义对齐，不能当正确率 |
| 数据库到已有本体映射有改进 | E13 p11表2 | 既有本体下的查询结果F1，非概念发现 |
