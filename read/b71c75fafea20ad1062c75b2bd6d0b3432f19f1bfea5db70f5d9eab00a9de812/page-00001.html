1# 代码包测试说明
2
3本文中的代码、配置路径及命令均以仓库的 `route2/` 目录为基准；文档链接可直接点击。
4
5在路线2目录执行 `uv sync --locked --extra test`、`uv run pytest -q`。
6
7测试使用代码动态生成的中性合成数据、模拟响应、真实 stdio MCP 协议，以及本地 HTTP 模型服务。不会读取企业数据，也不调用外部 LLM。
8
9- 增量构建：直接映射覆盖、当前 core 传递、Judge 修正、校验失败回滚、声明依赖顺序。
10- 检索：AgentScope 原生 ReAct 工具调用、二次查询、原文读取、冲突摘要、引用校验及预算。
11- 可选向量：开关与本地路径校验、精确余弦稳定排序、FTS 漏召回时外部本体向量补召回、core 仅从已接受表取语义邻居、MCP 已返回候选重排且保留原始名次。单测使用假向量，不需要下载模型。
12- 记录处理：条件引用、歧义、公式/JSON 局部引用、未处理范围、跨 schema 表名和复合键。
13- 可视化：预览数量限制和文本安全渲染。
14
15`test_local_external_rdf_import` 使用已打包的 gist，可以在无网络环境直接执行。KPIOnto 正文未发现明确的再分发许可，需从上游直接取得；它不是基础测试的依赖，见[公开本体说明](../PUBLIC_ONTOLOGIES.md)。
