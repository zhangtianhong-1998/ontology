24`code/RIGOR`、`code/AgentScope` 是未修改上游源码的 Git 子模块指针，查看源码时需在线初始化或提前转移；运行 `code/ontology_r2` 原型不需要它们。此路线没有 SAND、GRAMS 或 Steiner Tree 依赖。`config/example.yaml` 是较完整设计的配置草案，实际运行请用 `runtime.mock.yaml`。
25
26当前 `profiling.py` 已按列组统计 CSV 快照，`discovery.py` 可对合格字段建立完整 distinct 值索引，并在预算内对候选做全输入精确核验。`association_rules.py` 可选用受限 ReAct 探索条件化物理匹配，`semantic_cards.py` 与 `instance_bundles.py` 对记录值做有界检索和组包，再由 `group_incremental.py` 进行证据约束下的增量抽取。技术匹配不自动成为业务关系；候选遗漏、未决结果和预算外范围均单独报告。一般化 JSON 路径、异名值转换和真实数据的语义质量验证仍未完成。`config/profiling.design.yaml` 仍是设计草案，不是运行配置。

28不需要模型密钥即可复现本轮 3 条合成定义的工程检查：`uv run python scripts/run_group_compilation_experiment.py --output runs/measure-metric-demo`。生成的 `runs/measure-metric-demo/viewer.html` 可在本地打开；固定决策只验证分类门禁、关系编译与页面载荷，不代表真实数据上的语义准确率。

30无 Docker 的目标电脑继续运行本地原型。`ontology-r2 export-datahub` 可将已有 `meta_graph.yaml` 中的表/列元数据导出为 DataHub metadata-file；需要本地查询时，可另装 DataHub Lite，但 Lite 不提供图遍历或血缘。
