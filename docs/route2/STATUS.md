# 路线 2 当前实现状态

当前开发分支为 `codex/ontology-correctness-v14`，从 V13 的 `1be2ff59` 派生。2026-10-07 这轮先修复错误接受、复用中断、候选调度和调用计数，再做无外部 LLM 的小规模验证；没有启动新全量实验，也没有改写 V13 结果。需求、反例、复现命令和未完成项见 [V14 正确性整改](CORRECTNESS_V14.md)。

V13 审查记录的 21,807 个定义记录实例不等于业务事实实例化：该轮事实候选 1,600 个、事实实例 0 个。本轮小数据验证只证明指定来源合同下的闭环，不替代真实模型、未知数据集或百万行语义质量验收。

## 已实现

| 部分 | 当前行为与边界 |
| --- | --- |
| 本地元数据图 | 统一保存表、列、主键、源记录类型、声明外键和已核验技术关联。支持按表查询关联邻域，参与抽取组包。本地适配器采用 DataHub 兼容 URN 与导出格式；未运行 DataHub 服务，不由 DataHub 发现隐式关系，也不会上传元数据。 |
| 字段角色 | 先检查空列、审计列和排除列；对剩余未识别列，结合声明、样本和统计提出有界模型候选。固定角色与明确标识符声明冲突时，保留为引用并记录冲突；已有 name 列不会阻止其他匿名列分析；无注释时可以使用实际内容，但证据不足时保留未决。 |
| 字段关联 | 完整 distinct 倒排允许异名列候选；低基数判别列生成条件分支。标准名、别名和规范化转换在完整输入上重新核验。重复 ID 命中不直接确立业务关系。 |
| 连接性能 | 先去重引用值及作用域，聚合目标键，再核验命中、歧义和缺目标，避免重复值之间形成巨大的中间连接。语义组包按规则反查实际行，不组合不存在的坐标。 |
| 联合组包 | BM25 与本地向量召回定义候选；已核验技术关联提供相关记录上下文。定义模式只用于调度；引用差异、记录身份和公式差异仍保留。关联上下文不能直接当作概念相同或公式归属的证据。 |
| 本体生成 | 物理表类型与业务类型分开。概念、关系支持批量提出与逐包校验、复核、修复。类型保存完整来源定义，模型改写另存；SUM 等运算符不能单独成为度量类型。 |
| 关系及计算 | 根关系与登记的派生关系使用受控名称。可解析公式建立表达式树、操作数角色和依赖证明；未知符号、同名歧义、自然语言公式等保留未决。新增歧义会撤销过时的计算关系。明确且无例外的 unrestricted 来源声明保留为注释，不作为坐标等值限制。 |
| 复用与恢复 | 同快照、模型、提示词、排除策略及语义代码哈希的 checkpoint 可继续抽取，跳过已接受包的语义调用；旧检查点缺少代码哈希时拒绝恢复。完整完成的后续阶段可复用，不把 partial 改为 complete。恢复仍会导入、统计及扫描输入，尚未实现已有关系记录零访问或通用跨快照 CDC。新增独立 `reuse-facts` 入口，可重验已导出事实字段映射及来源定义后处理新快照；关系模板重放、同义融合与任意跨快照身份仍未完成。展示代码的修改不再使语义 checkpoint 失效。 |
| 实例化 | 定义模板成员与 exact 同一概念分开；事实按字段模板绑定实际坐标元组，不逐行调用模型。关系证据只覆盖经核验的范围。默认不复制全部物理记录的全部属性。 |
| 结果浏览 | 自动生成本体/元数据两个视图。圆形节点、关系标签、缩放和平移；元数据表级展示、按需展开列；右侧查看属性、公式、来源与证据。 |

## 本轮正确性修复

完整定义、固定/变量度量目标统一校验；文本规范化保留数值及语义符号；JSON 消歧限制在同一结构对象；成员关系要求完整肯定声明；数字风险保留是/否/未知并由实际匹配值重新核验。已有候选只有通过最终绑定校验才会阻止新类型归纳。关联 Agent 按缺证类型分配预算，稀疏关系文本改用非空 distinct 分层样本并报告未检查范围。缓存键排除预算、超时和请求间隔，事实归纳与绑定的阶段上限包含内部重试和格式修复。

## 尚不能声称解决的问题

- 跨快照入口只支持当前已实现的来源定义与事实字段合同；导出的关系类型保留供检查，但关系执行需要单独重放编译器。Measure 多层继承未开放，计算参数、期间和过滤范围不能自动改为 `is_a`。
- 混合用途表仍需要更细的行级分流。字段角色模型只能给出来源支持的候选，不能保证每种未知表结构都识别正确。
- 别名、条件探测、关联上下文和语义决策都有预算。完整输入扫描不表示全部潜在关联已召回；输出保留各阶段分母与遗漏范围。
- 配置表中的公式进入相关上下文后，仍需独立证明归属，不能因为技术连接成立就赋给某个指标。
- 同名指标还不能按已核验的行级定义引用分区绑定事实；范围检查尚不能表达全国/北京的域成员关系或公历年/2025的粒度关系。这些情况继续未决，不能靠名称猜测或放宽判断。
- 任意跨表业务事实的计算 JOIN、自然语言公式的可靠可执行化、跨快照实体稳定身份尚不完整。
- 没有真实企业数据及独立业务 Gold。工程测试、图大小、调用成功不等于业务语义准确率；Windows 真机效果也未验证。本轮只有页面脚本和几何逻辑回归，没有完成浏览器交互验收。

已完成的独立对照 v3 保留 8 条业务定义和 8 条计算依赖，但事实字段绑定与业务事实实例均为 0，9 个观测值候选仍未决。这验证了部分定义与计算依赖契约，没有完成事实实例化验收。固定来源样本的核对方法见[审计说明](SEMANTIC_SAMPLE_AUDIT.md)。

运行状态以对应目录的 `manifest.yaml` 为准，部分完成原因见 `partial_reasons`；后阶段失败也保留之前接受的本体产物。完整实验会另行记录实际输入、版本哈希、模型调用、阶段覆盖和未决项。
