# 路线2当前实现状态

本文中的代码、配置路径及命令均以仓库的 `route2/` 目录为基准；文档链接可直接点击。

路线2已能运行完整原型流程。字段统计与自动关联发现的升级项 P01—P06 尚未实现，这部分目前只有设计和统计口径的合成验证。

| 部分 | 当前状态 | 代码或设计依据 |
|---|---|---|
| YAML / CSV 导入、基础统计、元数据图 | 已实现；非空数、近似基数、有限取值样本 | `storage.py`、`pipeline.py` |
| 全字段映射、逐表增量、Judge 和失败回滚 | 已实现 | `incremental.py`、`validation.py` |
| 按计划执行记录关联 | 已实现；编码与作用域匹配、条件判断、有限公式/JSON 引用、FTS 候选 | `relations.py` |
| 企业知识补充 | 已实现；AgentScope 原生 ReAct 调用 stdio MCP，允许空结果并校验引用 | `knowledge.py` |
| 外部模型导入与术语对齐 | 已实现 RDF/CDM 子集，保留未支持语义 | `external.py` |
| LLM 流式 / 非流式、思考开关 | 已实现；所有模型调用共用配置 | `transport.py`、[配置说明](LLM_CONFIGURATION.md) |
| 抽取结果可视化 | 已实现本地页面与受限预览 | `visualization.py`、`viewer.html` |
| 自动字段候选发现与精确统计证据 | 待实现；P01—P06 未接入主流程 | [任务清单](implementation.md)、[字段统计设计](FIELD_PROFILING_DESIGN.md) |

当前的关系计划由 LLM 根据字段说明、统计、有限样本和补充知识生成，程序再按计划处理记录。它还没有先用全量字段倒排、包含率、条件内外分布等算法系统地找出候选字段对，再交给 LLM 判定。

因此，已知模式能执行并保留歧义；隐含关系能否被充分发现仍未验证。“统计口径已验证”只描述字段发现升级项，不能代表整个路线2，也不能把已有流程称为完整的自动字段关联发现算法。
