# 代码包测试说明

本文中的代码、配置路径及命令均以仓库的 `route2/` 目录为基准；文档链接可直接点击。

在路线2目录执行 `uv sync --locked --extra test`、`uv run pytest -q`。

测试使用代码动态生成的中性合成数据、模拟响应、真实 stdio MCP 协议，以及本地 HTTP 模型服务。不会读取企业数据，也不调用外部 LLM。

- 增量构建：直接映射覆盖、当前 core 传递、Judge 修正、校验失败回滚、声明依赖顺序。
- 检索：AgentScope 原生 ReAct 工具调用、二次查询、原文读取、冲突摘要、引用校验及预算。
- 记录处理：条件引用、歧义、公式/JSON 局部引用、未处理范围、跨 schema 表名和复合键。
- 可视化：预览数量限制和文本安全渲染。

KPIOnto 文件未打包，所以 `test_local_external_rdf_import` 会明确跳过。按 [Git 管理](../GIT_GUIDE.md) 下载该文件后，测试会自动执行；另一个使用测试代码生成 RDF 的对齐案例仍照常运行。

版本 0.3.0 于 2026-09-23 在独立目录运行：**60 项通过、1 项明确跳过、0 项失败**，耗时 24.35 秒。跳过项仅为缺少文件的 KPIOnto 集成测试。22 项新增接口用例覆盖 JSON/SSE、思考控制、ReAct、断流与超时。完整本地工程含 KPIOnto，61 项全部通过。测试均使用本地模拟服务，未调用外部模型。自研代码与同步后的原型工程一致，历史运行结果不随包上传。

这些测试验证代码行为和接口，不能证明真实模型的语义质量、企业文档有效性或百万条完整抽取性能。路线1和路线3目前为设计及依赖准备，不能按路线2测试通过推断其引擎已经实现。
