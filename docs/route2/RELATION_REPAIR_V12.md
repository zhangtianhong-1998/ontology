# V12：修复关系构建和类型复用

本轮沿用 V11 的 23 张模拟表及原有 CSV，不修改数据以适配抽取器。代码保持原型规模，优先复用已有证据、映射和执行模块，不引入新的图数据库或服务。

## 问题与实现

1. 模板把实例条件固定为类定义，又允许变化度量指向固定端点。现在将有来源依据的编号、成员和请求响应示例保留为实例字段；可变度量槽必须满足目标类型的完整名称／别名证据合同。类名与说明可来自同一记录的不同列，组合定义只能逐字引用。
2. 类型存在 exact 与 projection 两条构建路径。相同完整定义、根类型、作用域、单位及计算参数可以复用；等价候选和泛化候选不再仅因来源是投影而排除。不同含义的同名类型不能直接合并。
3. 非 Metric 的模板不能建立关系。补充一般对象对度量、维度、对象的有向配置引用合同；保留 Metric 与计算依赖原有约束。候选和端点校验均按具体谓词执行。
4. 配置把含 rule 的主键当关系文本。候选选择排除主键和纯标识字段；按配置规则及语义模式分配名额，避免一个模式占满队列。类型证据可以来自当前见证的完整记录绑定。
5. 术语 JSON 中的引用没有进入关系图。新增通用标量 JSON 路径发现，依据来源词项、作用域内唯一编码、成员名称／别名和成员归属声明构建路径。`denotes` 与 `member_of` 分别保存实例关系；`term_dimension_context` 表示词项经成员关联到维度，不能解释成词项等于整个维度。
6. 已接受的记录关联在完整绑定生成后没有重试。现在无模型重放既有关系决定；只有端点绑定变化才重新尝试。模型修复任务也按证据和相关候选去重，无变化时报告等待新证据，不能冒称缺口已解决。
7. 短引用编码出现在解释文字时导致整包失败。允许还原已知编码的解释文字，未知编码和无来源位置的证据引文继续拒绝；失败的结构化响应保存到本地轨迹。失败批次不再反复组成重叠批次。
8. 事实字段范围映射混用列名和常量。区分坐标列映射与全输入核验的常量范围列；保留单位证据要求。可配置一次字段级格式／映射修复，不进行逐行模型调用。
9. 模板修复只看到一个实例，容易把实例说明固定为类约束。对已有完整类定义证据的字段缺口，同表检索最多 16 个候选，补充最多 2 条当前源记录；要求类定义及身份一致、缺口字段确有变化，不扩大精确对齐权限。记录说明中的差异交由修复裁决，程序不直接删除约束。

## 关系及实例的边界

- 类型继承、业务关系签名、定义记录实例、维度成员和实际数值观测分别保存。存在一个类型签名不意味着两个类型的全部实例互相关联。
- 术语词项和其指称对象不能合并。成员节点显式标注成员角色，维度定义节点另有身份。
- 编号匹配只产生候选；业务谓词还需要来源语义。技术元数据图继续保存物理表、字段与引用，不能用技术连接冒充业务关系。
- 无注释、无明确成员声明或存在歧义时，新增确定性路径会保留未决并报告覆盖范围，不声称已经解决任意无注释数据。
- 分类属性、定义身份和适用范围分开比较。只有来源明确证明属于分类属性，才允许关系两端不同；租户、命名空间和版本冲突继续阻止关联。

## 验收

回归包含异名字段及非水果领域的 JSON 引用、歧义编码、作用域冲突、来源变化、错误度量模板、跨列定义、跨路径类型重复、无进展修复和错误关系方向。测试通过仅证明这些工程行为，不能替代新实验的语义评估。

启动前完整测试通过 1,243 项；另核验语义引用从源导入、校验、实例化到 HTML 导出的 mock 全链，并在全新 Dataset 中重放保存的证据。验收未调用真实 LLM。

使用 V11 已接受类型及相同输入进行无 LLM 的离线补全：16 个术语生成 16 条经成员到维度的路径，包含 10 个不同成员和 26 条指称／归属实例边。此检查不修改输入，不等于新一轮抽取结果。

结果新增 `semantic_reference_*.yaml` 与 `business_graph_coverage.yaml`。后者排除根节点、继承边和物理表节点，列出业务关系方向、连通块及孤立类型；连通性不是语义正确性的评分。

## 新实验

配置：`route2/config/runtime.full-v12.yaml`。新缓存：`route2/.cache/relation_repair_v12_llm`。保留 V11 输出作对照。

沿用 deepseek-v4-flash、最多 3000 次调用、总计最多 5 轮、串行调用间隔 0.2 秒；配置关系最多裁决 160 个候选。企业 MCP 和外部本体关闭。HTML 在抽取结束时自动生成。

启动前提交代码并检查配置及测试。使用现有 `scripts/run_local_experiment.py` 在独立后台进程运行；仅核对启动状态，不持续监控。全量读入不等于全部语义候选都经过 LLM，预算和未处理范围须保留在 manifest 中。
