### LLMs4OL 2024 数据集：迈向利用大语言模型进行本体学习

**摘要：** 从非结构化数据中进行本体学习（Ontology Learning，OL）已经取得显著发展，近期的进展通过引入大语言模型（Large Language Models，LLM）来增强这一过程的各个方面。本文介绍了 LLMs4OL 2024 数据集，该数据集旨在为利用 LLM 开展本体学习的研究提供基准，并推动相关研究的发展。作为 LLMs4OL 挑战赛的关键组成部分，LLMs4OL 2024 数据集面向三项主要的本体学习任务：术语类型判定、分类体系发现和非分类关系抽取。该数据集涵盖七个领域，包括词汇语义学和生物学功能，为评估基于 LLM 的本体学习方法提供了全面的资源。数据集中的每项任务都经过精心设计，以支持少样本（Few-Shot，FS）和零样本（Zero-Shot，ZS）评估场景，从而能够稳健地评估模型在不同知识领域中的表现；同时，通过提供用于公平比较的标准化基准，评估 LLM 在本体学习中的应用，填补该领域的一个关键空白。

**关键词：** 本体学习；大语言模型；数据集；LLMs4OL 挑战赛。

### 1 引言

本体能够为语义表达和互操作性提供良好的基础，因此在语义网中获得了广泛的应用和认可。网络上非结构化数据的增长，使得从非结构化文本中自动获取本体成为一个十分突出的研究领域。近年来，研究趋势正在从手工构建本体转向自动本体学习[1]。本体学习涉及从文本信息中自动识别术语、类型、关系以及潜在的公理，以构建本体[2]。

回顾本体学习的研究历史，直到2002年初[3]，大多数本体学习方法仍然依赖种子词或已有的基础本体，而不是从零开始构建新本体。此后，在2003年[4]，自然语言处理（NLP）技术在新概念抽取方面展现出潜力。然而，面向本体学习的关系抽取仍然具有挑战性。此外，基础本体中的先验领域知识依然是本体学习关注的核心。随着该领域的发展，2006年提出了“本体学习分层蛋糕”（ontology learning layer cake）这一概念[5]，用来组织和描述面向实际应用场景、从文本中学习本体这一过程中涉及的不同步骤。

本体学习分层蛋糕从底层到顶层依次包括：术语、同义词、概念、分类体系、关系、规则和公理。这反映了从较简单的形式向更复杂、更抽象的形式逐步推进的过程，每一步都建立在前一步的结果之上。它为理解本体学习过程及实现该过程的自动化提供了一种结构化方法。随后，在2011年，Hazman 等人[6]研究了多种本体学习系统，并将其划分为两类：①从非结构化数据中学习；②从半结构化数据中学习。他们还指出，当无法进行人工评估时，对本体学习开展五个层面的评估十分重要，这些层面包括词汇、层级、上下文、句法和结构。自2011年以来的研究以及2018年的综述[7]表明，结合语言学技术与统计技术的混合方法能够产生更好的本体。然而，由于各项研究所针对的领域不同，很难从各种方法中确定最佳技术。术语抽取的研究趋势转向了统计技术，而在关系抽取中，使用最多的仍是聚类方法。此外，多项本体学习评估表明，人工评估是最可靠的评估方法。

鉴于该领域的大多数方法都以统计方法或聚类模型为基础，大语言模型的出现推动了本体学习的范式转变。LLM 的特性使其适用于本体学习，而 LLMs4OL 范式[8]首次对此进行了研究。推动这一转变的一个原因是 LLM 的生成能力：这些模型在规模庞大、种类多样的文本上接受训练，具有类似领域专用知识库的特点[9]。2023年首次提出了 LLMs4OL 范式[8]，将 LLM 引入本体学习的三项重要任务：术语类型判定、分类体系发现和非分类关系抽取。此后，更多研究人员开始从不同角度参与本体学习任务的研究[10]—[13]。

语义网领域当前的研究趋势表明，研究人员对于利用 LLM 的兴趣日益增长[14]。为了以一致且可比较的方式评估本体学习方法，尤其是涉及 LLM 的方法，基准数据集至关重要。没有这样的基准，就难以有效评估研究进展并比较不同的方法[13]。为解决这一问题，本文引入了一个面向 LLMs4OL 范式各项任务的数据集，以填补利用 LLM 进行本体学习这一特定背景下基准评估数据集的空白。我们的核心贡献是创建了 LLMs4OL 数据集，旨在促进这一新兴领域中的一致性评估。该数据集首次在“ISWC 2024 第一届 LLMs4OL 挑战赛”中推出[15]，该挑战赛在享有盛誉的国际语义网会议（ISWC）上举办。挑战赛的主要目标是为研究人员提供一个共享平台，以便对其基于 LLM 的本体学习方法开展基准评测。通过建立这一数据集并发起 LLMs4OL 挑战赛，我们希望鼓励利用 LLM 进行本体学习的进一步研究与创新，最终使这一快速发展领域中的不同方法能够得到更加系统和公平的比较。

### 2 本研究的本体资源与领域

LLMs4OL 2024 数据集支持从词汇语义学到生物医学等多个领域。这种多样性有助于保证 LLMs4OL 2024 挑战赛中各项研究的全面性。下面详细介绍我们为构建 LLMs4OL 范式任务数据集而使用的各领域本体。

**词汇语义学。** WordNet[17]是一个大型英语词汇数据库，可作为自然语言处理及其他应用的丰富本体资源。它由普林斯顿大学开发，现已成为理解和表示词语之间关系的常用工具。WordNet 分为四种主要词性：①名词：概念、实体和对象；②动词：动作、过程或存在状态；③形容词：描述性的性质或属性；④副词：修饰动词、形容词或其他副词的词。每种词性都有各自的同义词集（synset）和关系，这有助于区分词语在不同语法语境中使用时所具有的不同含义。

**地理位置。** GeoNames 本体[18]是地理数据的一种形式化表示，对地理要素、位置以及相关信息进行建模。它是关联开放数据（Linked Open Data，LOD）云的重要组成部分，为地理数据提供机器可读的格式，以促进不同领域之间地理知识的整合、查询和共享。GeoNames 包含超过1,200万个地理名称和900万个唯一地理要素，例如城市、国家、河流、山脉、湖泊等。这使 GeoNames 成为进一步研究 LLMs4OL 任务的丰富本体资源。

**生物医学。** 统一医学语言系统（Unified Medical Language System，UMLS）[19]是由美国国家医学图书馆（National Library of Medicine，NLM）开发和维护的综合性生物医学本体。它整合了多种医疗卫生术语体系、编码系统和本体，形成一个统一资源，以支持自然语言处理、生物医学数据整合以及不同医疗卫生系统之间的互操作性。UMLS 元词库（Metathesaurus）是一个大型生物医学概念与术语数据库，整合了许多已有的术语体系和编码系统。它由多个来源词表组成，包括 SNOMEDCT_US[20]、NCI[21]和 MEDCIN[22]等知名本体。SNOMEDCT_US 为电子健康记录提供核心通用术语。NCI 则涵盖与癌症相关的临床诊疗、转化研究与基础研究，以及公众信息和行政活动所需的词汇。此外，MEDCIN 医学术语体系涵盖症状、病史、体格检查、检验、诊断和治疗。

**食品。** 食品本体（Food Ontology，FoodOn）[25]是一个由联盟推动的项目，旨在构建全面且易于获取的全球“从农场到餐桌”食品本体，准确且一致地描述世界各地文化中常见的食品。作为一种食品产品术语体系，FoodOn 支持粮食保障、食品安全、质量、生产、分销，以及消费者健康与便利性。

**网页内容类型。** Schema.org 词汇表[26]涵盖实体、实体之间的关系以及动作，并且能够通过文档完善的扩展模型方便地进行扩展。这些模式由一组“类型”构成，每种类型都关联一组属性，各类型按层级组织。总体而言，Schema.org 包含806种类型、1,476个属性、14种数据类型、90种枚举以及480个枚举成员。

### 3.2 GeoNames 本体——任务A和任务B

GeoNames 本体涵盖世界各地的地理位置。为了缩小研究范围，我们首先将数据集限制为使用英文字母表示的位置，从而得到一个词汇术语集合 $L$。GeoNames 使用要素代码（Feature-Code）[28]对各种地理实体进行分类。每个位置都关联一个要素代码，用来表示地理位置的类型，例如“道路”或“聚居地”。我们将这些要素代码映射到相应的名称，构建集合 $T$，总共在 GeoNames 中识别出680种不同类型。例如，要素代码为“S.RSRT”的术语“Elks Country Club”被映射到类型名称“resort”，即“度假地”。随后，我们根据 $T$ 对所得的 $(L,T)$ 配对进行训练集与测试集划分，约10%的数据用于测试，其余用于任务A的训练。

对于任务B，我们使用了 GeoNames 的要素代码。这些代码按层级组织，反映地理要素在粒度上的不同层次。它们分为九个主要类别：“行政区域”“水文要素”“区域”“聚居地”“道路与铁路”“点状地理要素”“地形”“海底要素”和“植被”。这些类别处于一个两层分类体系中的较高层级，由此产生680个具有“is-a”关系的配对。随后，我们按照70∶30的比例划分数据，形成训练集和测试集。

### 3.4 基因本体——任务A、任务B和任务C

对于术语类型判定任务，我们需要将词汇术语，即基因产物，映射到其泛化类型。这些类型来自基因本体的三个子本体：生物过程（BP）、细胞组分（CC）和分子功能（MF）。为了收集相关标注，我们使用 Python 脚本，通过以下 API 查询 GO 查询服务（GO Lookup Service，GOLR）：`https://golr-aux.geneontology.io`。查询返回的标注包含基因产物名称（`bioentity name`）、标签（`annotation class label`）以及所属本体分支等信息。随后，按照 `aspect` 字段对数据集进行分组，该字段对应子本体 BP、CC 或 MF，并删除重复项。

在收集和预处理数据之后，我们为每个子本体分别创建数据集，组织其中的基因产物 $L$ 及其对应的类型 $T$。为了保证数据集质量，我们设置了200的频次阈值，过滤低频术语，以减少噪声。随后，按照70∶30的比例将数据集划分为训练集和测试集，以确保能够稳健地评估执行术语类型判定任务的模型。所得数据集具有足够的规模，各子本体中的唯一术语数介于323与792之间。
