# CUET Zenith 参加 LLMs4OL 2025 任务 C：用于分类体系发现的嵌入—大语言模型混合架构

### 摘要

分类体系发现，即识别本体结构中的层级关系，是本体学习的一项基础性挑战。我们提交至 LLMs4OL 2025 挑战赛的方案采用混合架构，在生物医学知识领域〔子任务 C1：OBI〕和通用知识领域〔子任务 C5：SchemaOrg〕中处理这一任务。

对于 C1，我们将基于 Sentence-BERT 嵌入的语义聚类与使用 Qwen-3（14B）的少样本提示相结合，无需针对任务进行专门微调，即可实现领域特定的层级结构归纳。对于 C5，我们引入了一个级联验证框架，将句子 Transformer 模型 all-mpnet-base-v2 提供的深层语义表示、基于 XGBoost 的集成分类，以及使用 TinyLlama 和 GPT-4o 的分层大语言模型推理流水线相结合。为处理固有的类别不平衡问题，我们采用了基于 SMOTE 的数据增强和门控推理阈值。

实验结果表明，我们的混合方法取得了具有竞争力的性能，证实了将传统机器学习与大语言模型进行合理整合，能够为本体结构归纳提供高效且可扩展的解决方案。代码实现已公开提供。

**关键词：**本体学习；分类体系发现；大语言模型；混合架构；生物医学本体。

### 1. 引言

本体学习（Ontology Learning，OL）是人工智能领域对原始数据和文本数据进行结构化的基础。首届 LLMs4OL 挑战赛于 ISWC 2024 举办[1]，为评估大语言模型在核心本体学习任务中的应用效果提供了一个结构化的竞争性框架。作为对往年所奠定基础的自然延续，ISWC 2025 举办了第二届 LLMs4OL 挑战赛[2]，旨在拓展我们对大语言模型在本体学习方面潜力的认识。

我们的 CUET Zenith 团队参加了任务 C：分类体系发现。该任务重点识别本体类型对之间的层级关系，即 is-a 关系，其目标是在给定数据集中识别分类体系中的连接关系。

### 2. 相关工作

本体学习是人工智能和知识工程中的一项基础性挑战，其目标是自动从非结构化数据中获取结构化知识。早期的本体学习方法高度依赖专家驱动的方法，或词汇—句法模式挖掘、聚类等统计技术[13][14]。随着对可扩展性和领域适应性的需求不断增长，TF-IDF 分类器、层次聚类等机器学习技术被用于自动完成分类体系归纳和术语类型判定[15]。

近年来，语言建模的发展通过大语言模型为本体学习引入了新的范式。LLMs4OL 计划[1]在术语类型判定、分类体系发现和关系抽取等多个子任务中探索了这一潜力。在这些任务中，将基于嵌入的检索与基于 Transformer 的推理相结合的混合架构，正得到越来越广泛的采用。

已有研究证明了大语言模型在分类体系归纳中的有效性，这些研究通常利用混合架构，在传统方法与生成式推理之间取得平衡。LLMs4OL 2024 中的 SKH-NLP 系统[16]探索了使用 BERT 和 LLaMA-3，对 GeoNames 本体中的分类体系关系进行二元分类，展示了经过微调的大语言模型与零样本大语言模型在性能方面各自的相对优势。类似地，子任务 B 的参赛者[17][18]将传统分类器与生成式提示相结合，以近似构建跨领域的 is-a 层级结构。

### 4. 方法

#### 4.1 数据增强

BestTaxonomyClassifier 的训练语料由 Schema.org 本体中经过标注的（父类型，子类型）类型对组成，每个类型对都表示一个有效的 is-a 子类关系。为了将这一任务重新表述为二元分类问题，我们使用具有领域意识的启发式规则，系统地构造了数量相同的负例。

我们采用两种互补策略来合成负例：

1. **反向类型对：**约三分之一的负例通过颠倒正例类型对的方向生成。例如，将 `Movie → CreativeWork` 改为 `CreativeWork → Movie`，从而违反子类关系固有的非对称性。
2. **替换构造的类型对：**其余三分之二的负例，通过从类型词汇表中随机抽取另一类型并替换原始父类型来生成。为确保这些关系在语义上无效，我们排除了替换后关系有效、存在子串包含关系或词汇相似的候选替换项。

每个类型对均使用上下文化句子嵌入 all-mpnet-base-v2 进行编码，并加入词汇重叠和成对相似度特征。为处理分层划分后轻微的类别不平衡问题，我们采用了合成少数类过采样技术（Synthetic Minority Over-sampling Technique，SMOTE）。数据增强与类别平衡过程的定量汇总见表3。

**步骤3：使用 Qwen-3 进行少样本提示**

在流水线的最后一个阶段，我们通过少样本提示策略，将凝聚式聚类步骤得到的每个语义连贯的簇传递给大语言模型。为此，我们使用 Qwen-3，并通过 Unsloth 框架以4位量化模式访问该模型，以实现内存高效的推理。

#### 4.2.2 面向分类体系发现的混合模型：任务 C5

我们的方法将语义嵌入技术与级联式大语言模型验证相结合，以发现 SchemaOrg 中的分类体系关系。该方法采用多阶段流水线，将特征工程、集成分类和分层大语言模型验证相结合，以较高的精确率识别父子关系。流水线如图2所示，其结构通过门控验证，在较高精确率与计算效率之间取得平衡。

**图2　面向子任务 C5（Schema.org）的混合分类体系发现模型架构**

图中流程为：

Schema.org 数据 → 语义嵌入（all-mpnet-base-v2）→ 特征工程〔拼接、差值、Hadamard 积、余弦相似度、词汇特征〕→ Top-$k$ 候选生成〔$k=30$，$\tau_s=0.4$〕→ SMOTE + XGBoost → 概率阈值判断（$p$）。

随后分为两条路径：高置信度分支〔$p\geq0.75$〕直接生成高置信度预测；中等置信度分支〔图中标为0.4—0.75〕先经过 TinyLlama 二元检查，再经过 GPT-4o 概率评分〔$\tau_g=0.6$〕，得到经过大语言模型验证的预测。两条路径的结果最终汇总为最终预测。

## 第7页

**步骤1：语义嵌入与特征合成**

我们首先使用 all-mpnet-base-v2 Sentence Transformer[20]，将所有本体术语，包括训练集和测试集中的术语，编码为768维嵌入。这些嵌入能够捕捉本体概念之间的深层语义关系。

对于每个候选父子类型对，我们通过拼接以下内容，构造一个3,076维特征向量：

- 父类型嵌入和子类型嵌入。
- 逐元素差值和 Hadamard 积。
- 嵌入之间的余弦相似度。
- 词汇指标：共享 token 数量、前缀匹配和后缀匹配。

这一表示融合了语义相似度与词汇结构，使下游分类器能够捕捉多种关系线索。

**步骤2：候选生成与基于 SMOTE 平衡的集成分类**

对于每个测试类型，我们根据余弦相似度选择与其语义最相似的前 $k$ 个训练类型，其中 $k=30$，并仅保留相似度高于阈值 $\tau_s=0.4$ 的类型，以生成候选类型对。

为缓解类别不平衡，我们在拟合 XGBoost 分类器[22]之前，对训练集应用 SMOTE 过采样[21]。XGBoost 分类器使用100个估计器，最大深度为6，并采用对数损失进行优化。分类器输出概率分数，表示其对父子关系的置信程度。关键的运行阈值为：候选生成的相似度阈值 $\tau_s=0.4$；控制验证门控的机器学习置信度阈值 $\tau_{\text{low}}=0.4$、$\tau_{\text{high}}=0.75$。

**步骤3：基于大语言模型的级联验证**

中等置信度预测定义为：



$$
\tau_{\text{low}}<p<\tau_{\text{high}},
\qquad
\tau_{\text{low}}=0.4,\quad \tau_{\text{high}}=0.75。
$$



这些预测会被送入一个两级验证级联，该级联专门用于平衡推理准确性与计算效率。

**1. 使用 TinyLlama-1.1B 进行轻量级二元推理**

我们使用一个经过指令微调的小型大语言模型作为第一级过滤器。模型接收一个带约束的少样本提示词，其中包含五个人工精心选取的 Schema.org 父子类型示例。这些示例来自不同领域，例如创作作品、产品、地点和动作。

模型必须严格回答 `true` 或 `false`，从而快速排除语义上不合理的关系，同时保留在结构上具有合理性的关系。这一阶段的计算成本较低，并能最大限度地减少下游处理负担。

```
判断在 Schema.org 中，子类型是否为父类型的子类。
只回答 "true" 或 "false"。

父类型：CreativeWork → 子类型：Movie → 答案：true
父类型：Event → 子类型：Volcano → 答案：false
父类型：Place → 子类型：City → 答案：true
父类型：Product → 子类型：Smartphone → 答案：true
父类型：Action → 子类型：DanceAction → 答案：true

父类型：{parent}
子类型：{child}
答案：
```

上述类型名称依次对应：创作作品与电影、事件与火山、地点与城市、产品与智能手机，以及动作与舞蹈动作。

## 第8页

**2. 使用 GPT-4o 进行概率评分**

通过 TinyLlama 检查的类型对，会使用 GPT-4o 接受更细粒度的概率评估。我们向模型提供一个专门针对 Schema.org 的可能性查询，并将输出限制为 $[0,1]$ 范围内的单个数值：

```
在 Schema.org 中，'{child}' 是 '{parent}' 的子类型的可能性有多大？
请用0到1之间的数值表示。只输出一个浮点数。
```

这一过程将大语言模型的推理转化为一个可以通过阈值进行判断的定量指标。只有评分不低于 $\tau_g=0.6$ 的类型对才会被接受，从而为存在歧义的情况设定一个高精确率的判定边界。

**效率控制：**由于大语言模型推理占据了运行时间成本的主要部分，每次运行的验证调用最多处理1,000个类型对。候选项按照分类器不确定性从高到低的顺序优先处理，以确保计算资源用于最接近判定边界的情况。与对所有候选项进行直接验证的朴素方式相比，这种门控策略使大语言模型调用量减少了约78%。

**设计依据：**该级联利用了两种模型的互补优势：TinyLlama 充当低延迟的语义合理性过滤器，而 GPT-4o 则为剩余的困难情况提供高准确度的概率推理。这种设计使系统能够扩展到大规模 Schema.org 类型集合，同时不牺牲可靠分类体系发现所要求的精确率。

**系统提示词：**

```
你是一名经验丰富的 Web 本体专家，专门研究 Schema.org 词汇表。
给定一个 Schema.org 类型列表，请返回所有 is-a（父子）关系。
你的输出必须仅为一个字典列表，例如：

{"parent": "MovieSeries", "child": "TVSeason"}
{"parent": "MedicalDevice", "child": "Dentist"}
{"parent": "DrugPrescriptionStatus", "child": "DrugPregnancyCategory"}

不要解释。不要添加评论。只输出列表。
```

上述三组类型名称分别为：电影系列与电视季、医疗器械与牙医，以及药物处方状态与妊娠期用药分类。示例中的父子配对保留原文内容。

**用户提示词示例：**

```
以下是术语列表：
MovieSeries、TVSeason、MedicalDevice、Dentist、
DrugPrescriptionStatus、DrugPregnancyCategory。

仅输出上文所示格式的、由父子关系字典组成的 JSON 列表。
```

**最终预测汇总**

模型结合以下内容：高置信度分类器预测，即 $p\geq0.75$；经过交叉验证的大语言模型验证结果，即 $0.4<p<0.75$；以及限定为每个测试类型对应前 $k$ 个训练类型的候选生成，其中 $k=30$。

这种混合方法确保对潜在分类体系关系进行全面覆盖，同时通过多阶段验证维持精确率。这种门控验证确保仅在最能发挥作用的地方应用计算成本较高的大语言模型推理，而高置信度情况则完全由分类器解决。

## 第9页

通过联合语义—词汇特征空间、自适应阈值，以及在严格调用预算下运行的两阶段大语言模型级联，我们的方法超越了仅使用嵌入或仅使用大语言模型的基线。在该级联中，TinyLlama 用于二元合理性判断，GPT-4o 用于概率验证。该设计取得了我们在 C5 上的最佳得分，即 F1 为0.0866，相比纯嵌入模型提升了12.3%。

### 5. 结果与分析

#### 5.1 子任务 C1 的结果与分析

我们以表格形式展示了提交至 LLMs4OL 2025 挑战赛子任务 C.1——OBI 的结果。我们探索了多种方法，包括基于余弦相似度的过滤、基于提示词的大语言模型，以及结合两者的混合架构。表4给出了这些方法在精确率、召回率和 F1 分数方面的性能，结果来自官方 Codalab 排行榜。

**表4　子任务 C.1——OBI 的结果。F1 分数是用于排名的主要指标。**

| ID | 方法 | F1 分数 | 精确率 | 召回率 |
| --- | --- | --- | --- | --- |
| 1 | ST + 聚类 + Qwen-3 | **0.1142** | 0.2463 | 0.0744 |
| 2 | Sentence Transformer + 余弦相似度 | 0.0771 | 0.0951 | 0.0648 |
| 3 | BioBERT + 余弦相似度+ + Llama（零样本） | 0.0712 | 0.0830 | 0.0615 |
| 4 | BERT + LLaMA 零样本 | 0.0039 | 0.0052 | 0.0030 |

结果表明，孤立地使用大语言模型，无论是仅与余弦相似度结合，还是仅与聚类结合，所取得的性能都不够理想。例如，基于零样本 LLaMA 的方法，即使加入 BioBERT 或 BERT 过滤，其 F1 分数仍相对较低，这可以归因于缺少结构化的上下文信息。类似地，余弦相似度或聚类等基于相似度的无监督技术，能够有效捕捉表层语义关系，并降低计算复杂度。

相比之下，将这些方法整合到一个混合框架中，同时利用句子嵌入和聚类的语义分组能力，以及大语言模型少样本提示的上下文推理能力，可以显著提升性能。这种组合方法有助于在多种本体术语之间实现更好的泛化，所提出方法取得的更高 F1 分数反映了这一点。

#### 5.2 子任务 C5 的结果

我们为 LLMs4OL 2025 挑战赛的子任务 C5——分类体系发现，提出了一种新的混合架构。我们的方法协同整合了语义嵌入、机器学习分类器和大语言模型，以处理 SchemaOrg 本体中的层级关系预测任务。

核心创新在于一个多阶段过滤流水线：第一，使用 Sentence Transformers 和余弦相似度阈值生成语义候选项；第二，使用利用词汇特征与嵌入特征的 XGBoost／MLP 分类器，进行基于机器学习的概率估计；第三，通过对 Mistral-7B 和 GPT-4o 使用受约束的提示词，进行大语言模型验证。表5汇总了我们在官方 Codalab 平台上评估的表现最佳的配置。

**表5　子任务 C.5——Schema.org 的结果。F1 分数是用于排名的主要指标。**

| ID | 方法 | F1 分数 | 精确率 | 召回率 |
| --- | --- | --- | --- | --- |

最佳性能由 ID 1 取得，F1 为0.0866。该配置采用经过优化的集成方案，将 XGBoost、词汇特征〔共享 token、前缀／后缀检查〕以及级联式大语言模型验证系统相结合。关键创新包括：

- 使用经过 SMOTE 增强的训练数据，以缓解类别不平衡。
- 动态阈值设置：$\tau_{\text{sim}}=0.4$、$\tau_{\text{ML}}=0.4$、$\tau_{\text{GPT}}=0.6$。
- 使用 Schema.org 专用示例，进行上下文感知的少样本提示。
- 采用计算高效的过滤，将大语言模型调用限制在不超过1,000个类型对。

值得注意的是，较小的大语言模型，例如 ID 1 中的 TinyLlama-1.1B，在与 XGBoost 配合时优于更大的同类模型，这表明任务与模型之间的最佳匹配比单纯扩大模型规模更为重要。当过度依赖基于大语言模型的评分、从而削弱结构信号时，出现了最差的性能，即 ID 5。

这些结果证实，在混合架构中，由嵌入提供语义基础，并由大语言模型处理本体推理，可以为分类体系发现取得最佳平衡。与纯嵌入方法相比，其 F1 分数提升了12.3%。

### 6. 结论与未来工作

我们的混合框架表明，级联验证架构能够在本体学习中有效平衡精确率与计算效率。我们的验证级联范式，也为本体学习之外的知识密集型任务中、资源受限条件下的大语言模型部署提供了一种模板。

关键创新包括：

- 针对 OBI（C1）和 SchemaOrg（C5）进行领域优化的提示策略。
- 通过阈值门控的大语言模型验证，相比完整的成对评估，将推理成本降低约78%。
- 将句法模式与深层语义表示相结合的特征工程。

未来工作将探索：通过强化学习实现动态阈值优化；跨本体迁移学习；使用图神经网络确保结构一致性；以及面向新兴本体的少样本适应。
