在本研究中，我们提出了一种基于聚类的方法，利用先进大语言模型的表示能力来应对这些本体学习任务的复杂性。具体而言，我们采用了 `pranav-s/MaterialsBERT` [2]、`dmis-lab/biobert-v1.1` [3] 等领域专门化 Transformer 模型，以及来自 `grok.co` 和 `grok.com` 的大语言模型 [4]。选择这些模型，是因为它们与挑战赛各项子任务的领域相契合，使我们能够形成语义一致的术语簇和类型簇。我们的方法通过结合深度上下文嵌入、无监督聚类和自适应提示策略，旨在弥合词汇变体与领域专属语义之间的差距。

多项子任务的结果证实，由专门化大语言模型支持、聚类驱动的表示能够有效提升分类关系和非分类关系推断的性能。此外，我们在生物医学、材料科学和环境领域数据集上的比较评估，说明了所提框架对不同本体学习领域的适应能力。

### 1.1 任务 A：文本到本体

任务 A（Text2Onto）涉及从原始非结构化文本中抽取基础性的本体要素。它分为两个子任务：术语抽取（A1），识别填充本体所必需的领域专属词汇；类型抽取（A2），将这些术语归入抽象的类，从而为后续推理和语义集成建立结构化的知识表示。

### 1.2 任务 B：术语类型判定

任务 B 着重于为先前抽取出的词汇术语分配具有概括性的语义类别。该任务使用 OBI（生物医学研究）、MatOnto（材料科学）和 SWEET（地球与环境科学）等本体，将术语准确映射到其语义类，从而有效组织知识，并增强知识在不同应用中的复用能力。

### 1.3 任务 C：分类体系发现

任务 C 的目标是发现类型对之间的层次关系，即 *is-a* 关系，这对于构建结构化的分类本体至关重要。该任务涉及多个领域，利用 OBI（生物医学研究）、MatOnto（材料科学）、SWEET（环境科学）、DOID（医学疾病）、SchemaOrg（网络知识）、PROCO（化学过程）、FoodOn（食品科学）和 PO（植物生物学）等特定本体，支持稳健的层次推断与知识管理。

任务 D 关注分类层次之外的语义关系抽取。它旨在识别功能关系、组成关系和因果关系等有意义的关联，显著增强本体的实用性。其子任务涉及在 SWEET（环境与地球科学概念）、FoodOn（食品原料与制备方法）以及 GO（基因组关系）等特定本体中识别关系，以应对此前已经发现的挑战：大语言模型难以捕捉更深层次的语义细微差别。

### 2. 文献综述

文献 [5] 提出了面向本体学习任务的大语言模型领域专属持续学习和提示调优策略，所使用的模型包括 Llama-3-8B 和 GPT-3.5。研究表明，知识增强训练能够改善开源模型的性能，但商业模型在术语类型判定和分类体系发现基准上仍然表现更优。

文献 [6] 参加了 LLMs4OL 2024 挑战赛，针对术语分类、分类体系归纳和关系抽取等本体学习任务，提出了基于提示的方法和经典机器学习技术。借助 GPT-4o、Llama-3 等大语言模型，其方法在多项子任务中取得了前两名的成绩，凸显了生成式模型在自动化本体构建方面的潜力。

文献 [7] 提出了“语义塔”（semantic towers），这是一种用于本体填充与对齐的外在、层次化知识表示。通过在 WordNet 和 GeoNames 上开展全面实验，研究结果表明，尽管来自大语言模型的内在知识能够取得更高的基线准确率，但语义塔能够改善语义对齐和分类的稳健性，尤其是在低资源和存在歧义的场景中。

文献 [8] 提出了一种基于微调 GPT-3.5 的本体学习术语类型判定方法，并在 LLMs4OL 2024 挑战赛中，使用 WordNet、GeoNames 和 UMLS 等不同数据集进行了评估。其方法包括针对特定数据集的提示工程和少样本微调，在多数情况下取得了排行榜前列的名次。结果表明，大语言模型能够稳健地识别和分类不同领域的本体术语，但在 GeoNames 这类高度歧义的数据集上仍然存在挑战。

文献 [9] 引入了一种基于软提示调优的大语言模型框架，用于本体学习中的术语类型判定。该框架在标准数据集上优于基线方法，但在具有复杂类结构的领域中仍然面临挑战。

文献 [10] 通过将父子关系抽取建模为分类任务，处理本体中的分类体系发现问题。研究比较了经过微调的 BERT-Large 和 LLaMA 3 70B 模型，表明提示质量与微调都会对性能产生显著影响。LLaMA 略优于 BERT，但两个模型都在 GeoNames 数据集上取得了具有竞争力的结果。

文献 [11] 提出了一种将基于规则的方法与 BERT 模型相结合的混合方法，用于本体术语类型判定和分类体系抽取。研究表明，在 LLMs4OL 基准任务中，这种集成方法优于单独使用大语言模型的方法。

文献 [12] 提出了一条基于检索增强生成（RAG）的流水线，利用大语言模型实现自动化本体学习。该方法在术语类型判定和关系抽取方面展现出了良好的前景，但研究也强调了它在专门领域中的局限，以及模型微调的重要性。

### 3. 方法

### 3.1 任务 A 的方法：文本到本体（Text2Onto）

我们的方法面向三个专门领域——生态（ecology）、工程（engineering）和学术（scholarly）——并利用大语言模型 `gemini-2.5-flash` 的推断能力。整体流水线由三个主要阶段组成：（1）语料准备与表示；（2）层次关系抽取；（3）大语言模型推断与知识整合。

#### 3.1.1 语料准备与表示

领域专属语料以 JSON Lines（`.jsonl`）格式提供，其中每条记录包含唯一的文档标识符、标题和正文。各方法均以统一方式处理这些语料。

对于方法 B，我们将每篇训练文档与经过验证的术语—类型映射，即本体映射，显式关联，从而构建了一个知识增强训练集。由此形成的结构化、可检索示例数据库，为后续步骤中的语义检索提供了支持。

#### 3.1.2 层次关系抽取策略

我们开发了两种互补策略，利用大语言模型从文本中抽取术语—类型关系，即下位词—上位词关系。这两种策略的主要区别在于提供上下文引导的方式。

**方法 A：启发式引导的直接抽取**

该方法使用静态、与具体领域无关的提示，直接从经过关键词启发式筛选的文档中抽取术语—类型对。我们选择包含 `type(s)`、`subtype(s)` 或其首字母大写形式等词形的文档进行分析，这些词形常见于定义性或分类性语境。

对于每篇候选文档，提示包含以下内容：（1）明确要求识别并抽取术语及其对应类型；（2）提供一个单样本示例，演示预期的输入—输出 JSON 格式；（3）施加严格约束，禁止生成任何未出现在源文本中的术语或类型，以尽量减少幻觉；（4）在每条提示中加入明确的领域描述，即生态、工程或学术，为模型的推断过程提供上下文。

### 3.2 任务 B 的方法：术语类型判定

该任务的目标是，为给定的材料科学领域技术术语列表分配语义类别，例如属性、材料和单位。我们设计了一种多阶段混合方法，将确定性的词汇聚类与基于大语言模型的语义消歧相结合。工作流程包括三个阶段：（1）数据预处理与规范化；（2）词汇聚类与候选类型传播；（3）基于大语言模型的语义消歧与最终分类。

#### 3.2.1 词汇聚类与候选类型传播

我们将术语建模为无向图中的节点，边表示术语之间存在共享词元。通过深度优先搜索识别出的连通分量被定义为词汇簇，训练集和测试集的词汇簇分别计算。

对于每个测试术语，根据最大词汇重叠选择与之最匹配的训练簇。该簇中所有语义类型的并集，构成此术语的候选类型池。对于测试簇，将其成员术语的候选类型池合并，形成最终候选类型列表。对于没有词汇匹配的术语，默认使用训练集中全部类型，以尽可能提高召回率。

### 3.3 任务 C 的方法：分类体系发现

该任务的目标是，从一个扁平的 Schema.org 类型列表中，自动构建由父子关系，即超类—子类关系，所定义的分类层次结构。我们设计了一个混合式多阶段框架，将无监督聚类与基于大语言模型的关系抽取相结合。

#### 3.3.1 阶段1：粗粒度术语聚类

我们探索了两种聚类策略。

**基于词汇的聚类：**利用包含已知父子对的训练集，通过并查集图算法连接父节点和子节点，从而构建词汇骨架。根据测试术语与这些骨架之间的词汇重叠，将测试术语分配到相应簇中；不存在重叠时，则以这些术语为起点建立新簇。

**基于语义的聚类，作为优选策略：**使用领域专属 Transformer 模型，例如 SciBERT、BioBERT，将术语嵌入高维向量空间。采用 K-Means 算法，将术语划分为语义一致的簇；簇数通过对簇内平方和（Within-Cluster Sum of Squares，WCSS）应用肘部法 [13] 来确定。

#### 3.3.2 阶段2：通过大语言模型进行细粒度关系抽取

为提高精确率，每个簇都独立处理。我们为 `gemini-2.5-flash` 精心设计提示，要求模型：

（1）识别这些术语属于 Schema.org 词汇表，并理解其层次语义。

（2）抽取簇内明确的父子关系，即超类—子类关系。

（3）遵循结构化 JSON 输出格式，将关系对表示为包含 `parent` 和 `child` 键的对象。

非分类关系抽取任务旨在识别并形式化给定领域内实体之间的复杂联系，例如因果关系、部分—整体关系和功能关系。我们开发了两种不同的多阶段方法来应对这一挑战，尤其适用于事先可能未明确界定领域的场景。主要方法，即方法 A，是一个完全以大语言模型为中心的框架，依次执行从领域推断到关系抽取的知识发现过程。次要方法，即方法 B，是一个混合框架，将语义嵌入和算法聚类与后续基于大语言模型的推理相结合。

#### 3.3.5 方法 A：以大语言模型为中心的知识发现与关系抽取

这一主要方法利用一系列具有针对性的大语言模型提示，逐步构建上下文并抽取关系，模拟人类专家面对新领域时的推理过程。该过程分为三个依次进行的阶段。

#### 3.3.6 阶段1：自动领域推断

该过程首先面对的是一组缺乏上下文的实体。给定一个术语列表和一个潜在关系类型列表，首要目标是识别其背后的知识领域。

（1）**输入：**一个术语列表和一个候选关系名称列表。

（2）**过程：**我们通过提示，要求大语言模型 `gemini-2.5-flash` 扮演知识表示专家。模型被要求分析这些术语与关系的整体语义，从而推断它们共同的主题或科学领域。

（3）**输出：**模型生成一个结构化 JSON 对象，其中包含简洁的 `domain_name`，例如“食品科学与生产”，以及详细的 `domain_description`。这一描述概述了总体研究领域、概念的性质以及关系的典型作用。推断出的上下文至关重要，因为它构成了所有后续步骤的基础知识。

#### 3.3.7 阶段2：由大语言模型推断的语义聚类

在领域已经得到明确界定之后，下一阶段旨在将术语划分为语义一致的簇。这一步将问题空间从所有术语对之间的比较，缩减为更加聚焦的簇内分析。

## 第8页

（1）**输入：**术语列表、候选关系列表，以及阶段1生成的领域上下文，包括名称和描述。

（2）**过程：**向大语言模型发送一条新的提示。该提示提供完整的领域上下文，并要求模型扮演本体推理器。大语言模型的任务是构建一个以术语为节点的隐式知识图谱。它评估每一对术语；如果其关于已识别领域的内部知识表明，这对术语之间可以通过某个指定关系类型建立有效连接，就在它们之间形成一条无向边。随后，模型识别该图的连通分量。

（3）**输出：**模型返回一个由列表构成的列表，其中每个内部列表都表示一个由语义相关术语组成的簇。没有推断出任何连接的术语，各自形成单元素簇。

#### 3.3.8 阶段3：簇内关系三元组生成

最后这一阶段执行高精度任务：在前一步识别出的语义相关术语组内部，明确界定各项关系。

（1）**输入：**每个单独的术语簇和候选关系列表，并再次通过领域描述为其提供上下文。

（2）**过程：**为确保尽可能高的推理能力，我们在该任务中采用能力更强的模型 `gemini-2.5-pro`。对于每个簇，一条新的提示要求模型检查该簇内部所有可能的术语对。模型利用自身的领域专属知识，生成所有能够使用给定关系列表构成的有效关系三元组，其形式为 `head`、`relation`、`tail`，即头实体、关系和尾实体。

（3）**输出：**模型为每个簇返回一个关系三元组列表。随后，将这些列表汇总为一个统一、完整的列表，包含在语料中发现的全部非分类关系。

### 5. 结论

本文提出了一种建立在领域专门化大语言模型之上的、基于聚类的本体学习框架，用于解决 LLMs4OL 2025 挑战赛的四项主要任务。我们的方法将词汇结构、语义嵌入和基于提示的推断相结合，能够在术语与类型抽取、术语类型判定、分类体系发现以及关系建模等任务中实现可扩展的本体构建。

实验结果证实，聚类驱动的表示与基于 Transformer 的大语言模型相结合，能够在不同子任务和领域中取得具有竞争力的性能。我们在盲测以及侧重泛化能力的子任务中取得了显著成功。在这些任务中，结构化聚类改善了模型推理，并减少了领域推断中的噪声。然而，在语言复杂的领域，例如学术领域或 SWEET 本体中的表现，表明仍然需要更深入的领域对齐以及稳健的上下文建模。

未来工作将探索结合课程学习的微调、增强提示的个性化，以及整合符号推理或外部知识图谱，以解决语义消歧方面的局限。总体而言，本研究进一步表明，将无监督结构化与基于大语言模型的推理相结合，在实现自动化、领域自适应的本体学习方面具有良好前景。
