# 路线1：RIGOR 流程的 YAML 最小移植

目标：建立能运行的元数据基线，比较有无外部模型对本体生成的影响。

| 子路线 | 输入 | 外部模型 | 企业知识 | CSV |
|---|---|---|---|---|
| 1A | 三目录 YAML 元数据、固定一级模型 | 关闭 | 关闭 | 不读取 |
| 1B | 与 1A 完全相同 | 启用选定本体并对齐内部术语 | 关闭 | 不读取 |

一级模型是用户指定的建模约束，不算外部本体。表列注释属于输入元数据，不算企业文档 RAG。

最小产出：`ontology.yaml`、源结构覆盖清单、映射候选、来源依据、未决项、验证及成本报告。某个指标定义只存在于 CSV 时，这条路线无法生成该具体指标及其度量依赖。
